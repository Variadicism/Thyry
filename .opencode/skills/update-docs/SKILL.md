name: update-docs
description: Update the documentation in the `docs` directory with new information.
---

Please update the documentation in the `docs` directory with the new information provided in the `docs/updates.md` file.

Do NOT make any changes to unrelated parts of the documentation.

Add unresolved questions to the appropriate document within the `docs/unresolved` directory.

Add any rationale or explanations for decisions to the `docs/rationale` directory.

If there is any contradictory information, you must ask the user how to resolve the conflict.
